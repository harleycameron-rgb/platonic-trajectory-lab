# Platonic Trajectory Lab — research v0.1

Independent mathematical fixtures for the five Platonic solids: tetrahedron, cube, octahedron, dodecahedron and icosahedron.

## Run

```sh
python -m unittest discover -s tests -v
python -m platonic_lab
```

No third-party dependencies or Codespace required.

## Current scope

- Unit-radius deterministic vertex fixtures.
- Nearest-neighbour edge reconstruction.
- Vertex/edge/face counts and Euler characteristic.
- Centroid stability and cube-face-centre ↔ octahedron-vertex duality.
- PASS/FAIL geometry reports. UNKNOWN reserved for unimplemented trajectory/physical-invariance claims.

## Planned, not implemented
